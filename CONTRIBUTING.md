# Contributing to inite-club-mcp

Thanks for helping. The short version:

- **Have an idea, not code?** Open an issue with the
  [Product idea](https://github.com/inite-ai/inite-club-mcp/issues/new?template=product-idea.yml)
  template. Plain words are fine.
- **Found a bug?** Run `inite-club-mcp doctor`, then open a
  [Bug report](https://github.com/inite-ai/inite-club-mcp/issues/new?template=bug_report.yml).
  Never paste a token.
- **Want to change code?** [AGENTS.md](AGENTS.md) is the source of truth — for
  people and AI agents alike: ground rules, zones, the exact commands CI runs,
  the architecture map, and the idea → PR loop. With Claude Code, open the repo
  and run `/contribute`; with any other agent, say "read AGENTS.md and help me
  with …".

The MCP tools themselves live in the club server, not here; ideas about them
are still welcome as issues. Changes to sign-in, credential storage, the
bridge or the package identity (red zones in AGENTS.md) start as an issue that
a maintainer approves before code.

Security problems: please don't open a public issue — see [SECURITY.md](SECURITY.md).
