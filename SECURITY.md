# Security policy

**Do not open a public issue for a vulnerability.** Report it privately:

- GitHub: **Security → Report a vulnerability** on this repository
  (private vulnerability reporting), or
- email **security@inite.ai**.

Include what is wrong, how to reproduce it, and the version
(`npx @inite/club-mcp --version` or `package.json`). We acknowledge within a few
working days and credit reporters who want it.

In scope: this MCP server's code — its tools and their inputs, any network
fetches it makes, how it stores or sends credentials, and the published
package. Issues in a hosted INITE service it talks to are reported the same
way.
